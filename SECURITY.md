# Security reports

For a suspected vulnerability, contact io7 privately at **office@io7.net** with
the subject `FreePDF security report`. This is io7's published GitHub organisation
contact. Ask for a secure transfer route before sending confidential documents,
passwords or detailed exploit material. Do not upload those to public issues.

Include the FreePDF version, runtime/OS, affected operation and, when possible,
an original minimal reproducer without personal or customer data. GitHub private
vulnerability reporting is not currently enabled for this repository; a public
issue is not a substitute for private disclosure.

Reports and maintenance are handled on a best-effort basis with no response-time
guarantee. Fixes target the latest FreePDF patch and maintained runtimes. See
`docs/support-policy.md` for the supported feature scope and release gates.
