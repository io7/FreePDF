# FreePDF 7.0.0 development validation

This is `7.0.0-rc.2`, not a stable or published NuGet release. The MIT Preview 1 source
is imported with ancestry; independent changes are reviewed separately below.

## Independent corrections

| Requirement | Implementation | Evidence |
| --- | --- | --- |
| Tolerate non-name dictionary keys | Coerce string/integer keys to names; reject other types | `ReaderToleranceTests`: read/save/reopen and rejection fixtures |
| Legacy name bytes | Strict UTF-8 first, then current-culture ANSI with CP1252 fallback | UTF-8, literal replacement character, CP1252 and Shift-JIS fixtures; no claim that ambiguous bytes identify their original encoding |
| PNG memory failure | Exclude `OutOfMemoryException` from both importer fallback catches | Synthetic impossible array length; ordinary invalid image still uses fallback |
| Signature field collisions | Traverse root/nested fields with cycle guard; select first unused SignatureN | Existing fields and two real insertion calls; dummy signer, no cryptographic validity claim |
| Font cache races/staleness | Atomically publish immutable weak-reference pair and font properties | 40,000 parallel conversions plus same-font mutation |
| Core StartFigure (#396) | Track a pending new subpath and preserve it across cloning | Two synthetic path-operator tests and visual fixture |
| Fully merged table (#358) | Find minimum vertical extent among visible cells of a starting row | 2×2/3×3 merge regressions; visual fixture plus normal multi-page tables |
| Truncated hexadecimal strings | Detect EOF in both reader scanners; content whitespace/odd-nibble support | Bounded malformed-content cases and valid odd/whitespace cases |
| Trailer loops (#266) | Reject repeated and out-of-file cross-reference offsets | Child-process timeout tests, valid incremental-update control |
| Cyclic page trees (#361) | Iterative traversal with repeated-node detection | Cycles, repeated children, and a valid 2,000-node tree |
| Incorrect stream lengths (#394) | Bound repair and allocation by the next file object or EOF | Negative, short, long and correct lengths; later stream preserved through save/reopen |
| Inherited page attributes (#375) | Apply inherited values before page initialization; isolate sibling overrides | MediaBox, CropBox, Rotate and Resources in Modify/Import modes and round trips |
| Hybrid cross-references (#388) | Read XRefStm before Prev; reserve current compressed objects | Original hybrid PDF, compressed-object resolution and newer-revision precedence |
| Multiple content streams (#345) | Isolate graphics state using separate streams without modifying shared originals | Filtered/unfiltered streams, trailing comments, prepend/append and shared-page content |
| Indexed PNG transparency (#392) | Advance each real pixel's alpha position and ignore row padding | 1/4-bit odd/even widths, partial alpha, omitted opaque entries and 8-bit controls |
| Nested composite glyphs (#348) | Visit newly discovered component glyphs when constructing subsets | Original font with unmapped nested components; subset contents and rendered bars |
| Incremental content preservation (#302 category) | Select each compressed object by its active xref stream/index | Original two-revision PDF in Modify/Import modes; save/reopen and invalid-index rejection |
| Shared content ownership (#369 category) | Reuse existing typed streams when another page accesses them | Single-stream and content-array fixtures; original held object stays usable |
| Semantic save/reopen | Verify document values after repeated saves and typed access | Text, annotations, URI links, named destinations, form values and attachment bytes |
| Earlier fixes | Carry gradient state reset, inline-image EOF, zlib footer/framing | Earlier 6.2.5 regressions retained |

Source inputs: permitted MIT snapshots, public issue facts and changelog
requirements, original fixtures, RFC 1950. Later AGPL PDFsharp implementations
were not read or imported. `PROVENANCE.md` records details and asset licences.

## Release-candidate preparation (2026-10-31)

- **127** local Linux/.NET 10 regressions pass. Eight new preservation/semantic
  tests run against baseline `65d4e28794c7a3f43ef40176bcc62a4e6af3be1b` give
  **six failures and two passes**; all eight pass with the corrections.
- The local lab has **23 cases**: ten zero-delta matches, thirteen visible
  reviews, no candidate/comparison failures and eight explicit reference failures.
- `io7.FreePDF` and `io7.FreePDF.MigraDoc` have separate package identities,
  retained notices and an internal package dependency. A package-only consumer
  rendered PDF/RTF, reopened the PDF and loaded all eleven packaged assemblies.
- Branch and PR CI for `d36de2b` passed: **127** regressions on Linux/Windows
  .NET 8/10, **120** on Windows Framework 4.7.2, and package-only installations
  on Linux/Windows .NET 8/9/10 plus Windows Framework 4.6.2/4.7.2. The three
  comparison profiles also passed. See Actions runs `41196131565`, `41196131564`
  and `41196131507` for branch evidence; final deployment provenance is checked
  separately.
- Windows restore was found to add runtime sections to the reference lockfile.
  Both Windows runtime identifiers are now recorded explicitly, CI restores in
  locked mode, and comparison/bundle scripts reject changed CI checkouts.
- These fixes read incremental input correctly for the covered fixtures. Saving
  rewrites the PDF; it does not preserve signatures or implement incremental saving.

## RC2 release hardening (2026-10-31)

- **188** local Linux/.NET 10 regressions pass. The new CMS partial-read fixture
  failed before the correction. The initial 32-input mutation corpus exposed
  16 uncontrolled missing-trailer errors; all now open or report `PdfReaderException`
  inside the process time/memory budgets. A test-process exit race found during
  the full run was corrected separately from the library.
- Twenty-four checksum tests cover RFC digest vectors, a million-byte vector,
  offsets, padding boundaries, chunking and reuse against platform MD5. They
  support replacing the inherited helper whose historic third-party licence
  evidence was incomplete. Framework additionally checks nullable dictionary
  values and preservation of existing keys.
- Installed RC2 packages produce ten original workflow PDFs: multipage invoice,
  merge/stamp, two AES variants, three PDF/A profiles and three CMS digest variants.
  The local outputs pass qpdf structural checks, Poppler rendering/text checks,
  attachment-byte checks, veraPDF **1b/2b/3b** profiles and Poppler signature
  verification. Valid PDF files with deliberately altered signed bytes are
  rejected by the signature verifier. Wrong encryption passwords are rejected.
- The 23-case local lab retains **10 matches, 13 documented reviews and no
  candidate/structural failures**. All 23 candidate PDFs also pass independent
  qpdf and Poppler checks. The semantic fixture now includes a proper form default
  appearance, eliminating a Poppler warning in the original fixture itself.
- All **44** API comparisons pass: eleven assemblies across four targets against pinned
  MIT Preview 1 metadata, including parameter names, without suppressions. The
  v6 comparison remains a major-version migration report rather than a promise
  of v6 binary compatibility. See `migrating-to-7.md`.
- Package checks now retain complete dependency inventories, licences/notices,
  archive hashes and current NuGet advisory results. A separate plain `7.0.0`
  rehearsal uses its own package cache and verifies all eleven assembly versions.
  CI repeats installation on Linux/Windows modern .NET and Windows Framework.

These local results precede CI and deployment confirmation. Consult the exact
source revision's Actions results and deployment receipt for those proofs. The
gate configuration alone is not a completed Windows run or a stable publication.

## Stable-release gates

The API/migration, package/advisory/licence, independent output validation,
bounded malformed-input/application-workflow, runtime-policy and plain-version
package-rehearsal gates are now implemented. Every release must pass them on its
actual source revision; then a maintainer reviews and authorizes publication.
See `support-policy.md`, `dependency-audit.md` and `migrating-to-7.md` for scope.
The typed v7 form model contains placeholder classes; the low-level checkbox
fixture does not certify general form filling/flattening. No PDF/UA or
complex-script shaping claim is made.

## Approved Tomahawk25 installation (2026-10-30)

The viewer is live at `http://192.168.1.212:4817`. The baseline bundle contains
library commit `3cf4bb11bf6f315f5d9b46e56825812a6f2a0adc` and its own .NET 10.0.13
runtime. The core and comparison workflows passed for both branch and PR builds;
the comparison workflow executed Linux .NET 10 and Windows .NET 10/Framework 4.6.2.

The first host run identified missing Visual C++ DLLs that CI images already
provided. The installer now extracts three hash- and signature-verified Microsoft
14.51.36247 runtime DLLs privately beside MuPDF. No shared runtime installer ran.

Both scheduled-task runtime profiles then completed under LocalService with
MuPDF 1.28.5: nine zero-delta matches, three documented reference-defect reviews,
and zero failures each. The generated PDFs, raster pages and reports were checked
through the LAN viewer, including every case/page in both runs. Browser checks
covered run switching, overlay at 75%, difference view, multi-page navigation,
downloaded PDF, hidden unavailable reference links, refresh, and 390px layout.

The viewer task starts at boot and has a one-minute recovery trigger with
duplicate starts ignored. A process-stop test showed that the failure-restart
setting alone did not recover the process on this host, so the explicit trigger
was added. After stopping only the verified viewer process, the recovery trigger
started a new process and restored health within 42 seconds without a manual
start. The browser could still load both runs and their images. The nightly
task runs both profiles at 03:17; its completed invocation returned success.
The inbound firewall rule is restricted to `192.168.1.0/24`. These checks cover
the new FreePDF application; the shared host was not rebooted or reconfigured
outside the approved FreePDF installation.
