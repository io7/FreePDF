# FreePDF for .NET

FreePDF makes, reads and changes PDF files in .NET, under the MIT licence. It continues PDFsharp and
MigraDoc 6.2.4 with the same namespaces, and adds form filling and creation, digital signatures, Factur-X
invoices, accessible PDF and text extraction.

```
dotnet add package io7.FreePDF
```

- [Guide](guide/index.md): your first PDF, text, fonts, shapes, images, many pages, existing files, links
  and passwords. None of it needs MigraDoc.
- [API reference](reference.md): every public type and member.
- [Text extraction](text-extraction.md), [accessibility scanner](accessibility-preflight.md),
  [migrating from PDFsharp 6.2.4](migrating-to-7.md), [support policy](support-policy.md).

Source code, issues and release notes: https://github.com/io7/FreePDF
