# FreePDF 7.12.0

`freepdf-a11y` now lists the PDF/UA-1 requirements in the Matterhorn Protocol
1.1. You can also ask veraPDF to check the same document as the native scanner.

## Inspect the requirements

```sh
freepdf-a11y --requirements
freepdf-a11y --requirements --format json --output requirements.json
```

The inventory covers 137 conditions. Of these, 87 describe machine checks,
48 require human review and two refer to other requirements. Each entry cites
its source and starts with the document outcome `NotAssessed`.

## Run an independent check

Install veraPDF separately and pass the path to its launcher. On Windows, use
the path to `verapdf.bat`.

```sh
freepdf-a11y document.pdf --verapdf /opt/verapdf/verapdf --format json --output audit.json
```

Both validators inspect the same copy of the PDF. The combined JSON report uses
schema version `2.0`. Read `native` for the FreePDF findings and
`independentValidation` for the veraPDF result, version and profile. SARIF
records one run per validator. Native-only scans use the 7.11 JSON format.

If either validator finds a defect, the command exits with `1`. For example,
if FreePDF finds a missing document language and veraPDF is unavailable, the
combined report shows `Incomplete` and sets `hasFailures` to `true`. Exit code
`3` means a check could not finish and neither validator found a defect.

When both validators finish without a detected defect, the default exit code is
`2`. The explicit `--policy automated` option gives `0` in that case. A person
still needs to check reading order and whether descriptions convey the intended
meaning.

## Upgrading from 7.11.0

The tool requires .NET 10. When your NuGet source lists 7.12.0, update an
existing global installation with this command.

```sh
dotnet tool update --global io7.FreePDF.Accessibility.Tool --version 7.12.0
```

If your application uses the FreePDF libraries, update its FreePDF packages
together and rebuild for assembly version `7.12.0.0`.

The package tests run the installed CLI with veraPDF 1.30.3 on Ubuntu 24.04 and
Windows Server 2022. For the full report format and coverage details, see the
[veraPDF guide](../accessibility-verapdf.md) and the
[requirements inventory](../accessibility/README.md).
