# FreePDF 7.14.1

FreePDF 7.14.1 makes the accessibility scan's time limit and cancellation
token work while the PDF is opened. `freepdf-a11y --timeout` now covers that
step too. Upgrade if you scan files you do not control. The public API is
unchanged.

## Fixed: the scan could not be stopped while it opened the PDF

The 7.14.0 documentation said that `MaxDuration` did not stop the opening of
the PDF and that the cancellation token did. Neither did: the scanner checked
both only after the reader had read the whole file. Under `--timeout 1`, five
synthetic files within the default 64 MiB `MaxFileBytes` ran for 2.6 to 10
seconds. The slowest, 60 MiB of 1.5 million small objects without a
cross-reference table, also ended only after 13 seconds when its scan was
cancelled after 200 ms.

The reader now checks the limit and the token as it reads. Both stop the scan
less than 0.4 seconds after the limit, and the same five files now end after
about 1.1 seconds under `--timeout 1`. A limit reached while the file opens
gives the result of a limit reached later: an `Incomplete` report that says
`Scan exceeded MaxDuration.`, or `OperationCanceledException` for the token.

## Memory used to open a PDF

Opening a PDF keeps all its objects in memory, about 500 bytes each. A file
within `MaxFileBytes` that packs millions of small objects into compressed
object streams can therefore need several GB: 19 MiB with 3 million objects
used 1.5 GB and opened in 6 seconds, well within the default `MaxDuration`.
This release does not limit that memory. Scan untrusted PDFs in a separate
process with memory and time limits.

## Changed results

- A scan whose limit runs out while the file opens now ends there, without
  failures, and the CLI exits with `3`. In 7.14.0 the file opened completely
  and the first checks could still report failures, so the CLI exited with `1`.

## Upgrading from 7.14.0

The tool requires .NET 10. When your NuGet source lists 7.14.1, update an
existing global installation with this command.

```sh
dotnet tool update --global io7.FreePDF.Accessibility.Tool --version 7.14.1
```

If your application uses the FreePDF libraries, update its FreePDF packages
together and rebuild for assembly version `7.14.1.0`. No API change.

## Validation

All 7.14.0 release gates apply, plus:

- 1,334 regression tests in all (1,330 in 7.14.0). Four new tests stop the
  reader by `MaxDuration` and by cancellation, with and without a
  cross-reference table. All four fail on 7.14.0 and do not depend on timing.
- One independent static review by OpenAI Codex (gpt-6-astra). It found
  nothing that changes a result. Some steps of opening still run to their end
  before the next check: one very long token, parts of rebuilding damaged
  cross-reference data, decoding and decrypting a stream, and preparing pages,
  form fields and annotations at the end.

See the [preflight guide](../accessibility-preflight.md) for all scan limits.
